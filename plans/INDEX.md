# Catalogue of the plan material

89 images of Gino Valle's IACP housing on the Giudecca (*Alloggi Giudecca —
Legge 25.02.80 — Area Trevisan*). The index number `n` is used throughout
`docs/ANALYSIS.md`. `SE nn` = sheet number of the executive drawings (GT 80,
1984–85). Coordinates as in `docs/ANALYSIS.md` §2 (X/E east → west, Y north →
south, 1 module = 1.65 m).

**Kinds:** plan · section · elevation · detail · axo (axonometric/perspective)
· photo · other. **Use:** ★ primary source for the model, ○ supporting,
– context only / not used.
